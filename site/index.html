AgentDyno is the dyno bench for local coding agents. It scans your machine, fits the right open model, launches it correctly — then proves, with a five-probe exam on your own hardware, that the model can actually drive tools before you wire up Claude Code, OpenCode, or Aider.

Run the exam Source (Apache-2.0)

Local, free, open source. No account, no telemetry, no paid tier — the entire category exists because people are done with subscriptions.

// the problem

"It fits" is not "it works"

Fit calculators check memory. Then your agent silently fails: tool calls arrive as raw XML, edits report success while no file changes, models fall over once more than five tools are registered. All documented failure modes across Goose, OpenCode, Aider, Cline, and Continue.

Every tool has half the answer

Fit tools stop at a number. Agent CLIs are hardware-blind. Managers launch models but never test them as agents. Nobody hands you proof.

The failure is per-machine

The same model behaves differently per quant, context size, and memory budget. A leaderboard can't answer for your laptop. Only a measurement on your hardware can.

Illustrative output. Grades: A — all probes pass at usable speed. B — core pass, limited context or speed. C — chat only. F — cannot drive tools. A grade C is printed as proudly as an A; honesty is the product.

// quickstart

# macOS (Apple Silicon or Intel), Linux; Windows experimental
git clone https://github.com/paromitapa/agentdyno && cd agentdyno
npm install && npm run build

node dist/src/cli.js scan     # what this machine really has
node dist/src/cli.js fit      # which models fit, ranked, max agent context
node dist/src/cli.js pull qwen2.5-coder-7b
node dist/src/cli.js serve    # managed llama-server, correct flags
node dist/src/cli.js doctor   # the exam: 5 probes, grade A-F
node dist/src/cli.js connect claude   # wire an agent to the VERIFIED server

Under the hood: honest fit math from real GGUF geometry (weights + KV cache + overhead vs. your platform's true budget), SHA-256-verified downloads, and llama.cpp's llama-server — which natively speaks both the OpenAI and Anthropic APIs.

// honest answers

Is this another fit calculator?
No. llmfit (30k+ stars) already answers "does it fit" well. AgentDyno answers "does it work as an agent, on this machine" — and keeps the transcript as proof.
Will a 7B model replace my Claude subscription?
For many agentic edits on a 16 GB laptop: no, and AgentDyno will tell you so with a grade instead of letting you find out through silent failures. What it gives you is the best verified setup your hardware can honestly support — private and free.
Can I point Claude Code at this?
Technically yes — the managed server speaks the Anthropic Messages API and connect claude prints the env vars. Note: Anthropic has not publicly stated a position on third-party backends (claude-code#5577). OpenCode and Aider are fully-open first-class targets.
What data leaves my machine?
Nothing. Downloads come from Hugging Face and GitHub; inference is local; there is no telemetry of any kind.
